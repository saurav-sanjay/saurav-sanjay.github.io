Welcome! This is the first post in the new blog section of this site.

Write posts as Markdown files placed in _posts/ with the filename format:

YYYY-MM-DD-your-post-title.md

Example:

- _posts/2026-04-18-welcome-to-my-blog.md

Jekyll will render each post to its own page automatically on GitHub Pages or when running `bundle exec jekyll build` locally.
